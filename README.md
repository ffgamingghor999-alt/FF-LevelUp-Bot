# TEAM 84FF - FreeFire Account Dashboard (Safe Demo)

This project is a safe local dashboard prototype for managing a list of account profiles, persistent device IDs, token cache placeholders, and simulated match stats.

Important:
- It does not interact with the Free Fire game client or game servers.
- It does not automate gameplay or bypass any anti-cheat or platform rules.
- It is intended as a learning/demo starter for dashboard UI, config management, and simulation flows.

Features included:
- Multi-account dashboard
- Persistent device profile tracking
- Token cache placeholders
- Region priority config
- Live log feed
- Simulated EXP gain loop
- Web dashboard UI

Start:
  python Main.py

Then open:
  http://localhost:20335
